# BARBER HUB — React Project

Responsive multi-page static React website concept for a local barber shop in Lucena City.

## Pages
- Home
- Services & Prices
- Haircut Ideas
- Online Booking
- About & Contact

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite.

## Notes
- Built with Vite, React function components, JSX, React Router, Bootstrap and custom CSS.
- Booking form validates on the client and displays a confirmation preview. It does not save bookings or connect to a real barber schedule/database.
- Prices, sample barbers, hours and appointment slots are demo content. Replace them with verified shop details before publishing.
- For the class deliverable, deploy the `dist` build using GitHub Pages, Netlify or Vercel and upload the source to GitHub.
